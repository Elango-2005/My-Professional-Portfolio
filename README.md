A modern, responsive personal portfolio website built with **HTML, CSS, and JavaScript** to showcase my skills, projects, experience, and contact information.

## 🌐 Live Portfolio

**[Visit My Portfolio](https://elangosdev.netlify.app/)**

## ✨ Features

* **Responsive Design** — Optimized for desktop, tablet, and mobile screen sizes.
* **Interactive Navigation** — Smooth section-based navigation with an active menu state.
* **Animated UI** — Scroll-based animations and visual effects for a dynamic user experience.
* **Preloader Animation** — Lottie-powered loading animation.
* **3D Hero Experience** — Interactive Spline 3D content in the home section.
* **About Section** — Personal introduction, goals, and profile highlights.
* **Skills Section** — Technology and development skills presented through an interactive interface.
* **Projects Section** — Dedicated area for showcasing technical projects.
* **Contact Form** — Client-side validation with form submission handling.
* **Mobile Navigation** — Collapsible navigation for smaller screens.

## 📱 Responsive Design

The portfolio includes dedicated responsive styling for mobile devices. The mobile stylesheet adapts navigation, hero content, layout, sizing, and spacing for smaller screens.

## ⚙️ How to Run Locally

Because this is a static frontend project, no backend installation is required.

### 1. Clone the repository

```bash
git clone https://github.com/Elango-2005/My-Professional-Portfolio.git
```

### 2. Open the project

```bash
cd My-Professional-Portfolio
```

### 3. Run the website

Open `index.html` in your browser, or use a local development server such as **VS Code Live Server**.
